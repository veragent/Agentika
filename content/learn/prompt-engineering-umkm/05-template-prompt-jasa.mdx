# Template Prompt untuk Usaha Jasa

Template khusus untuk salon, barbershop, bengkel, les privat, fotografer, katering, cleaning service, dan semua usaha jasa.

## 1. Penawaran Jasa yang Meyakinkan

```
Kamu adalah konsultan bisnis jasa. Buatkan teks penawaran untuk
layanan [NAMA LAYANAN], harga [HARGA/PAKET].

Sertakan: apa yang didapat klien (rinci [3-5 POIN]),
kenapa harus pilih kamu ([KEUNGGULAN, mis. pengalaman 5 tahun]),
dan garansi [GARANSI, mis. "tidak puas? gratis revisi"].
Struktur: masalah klien → solusi → bukti → harga → CTA.
Maksimal 200 kata.
```

## 2. Deskripsi Portofolio/Hasil Kerja

```
Buatkan deskripsi portofolio untuk proyek: [JENIS PROYEK,
mis. "makeup wisuda"]. Ceritakan: kondisi awal klien
([KONDISI]), apa yang dikerjakan ([TINDAKAN]), hasilnya
([HASIL]). Kemas sebagai studi kasus mini yang bikin calon
klien membayangkan dirinya. Maksimal 120 kata.
```

## 3. Follow-up Penawaran yang Belum Dibalas

```
Buatkan pesan follow-up sopan untuk calon klien yang sudah
menerima penawaran [LAYANAN] 3 hari lalu tapi belum merespons.
Jangan terkesan memaksa atau putus asa. Beri nilai tambah:
[mis. "sekadar info, slot minggu ini tinggal 2"].
Tawarkan opsi: lanjut, tanya-tanya, atau tolak dengan baik.
Maksimal 70 kata.
```

## 4. Template Price List Profesional

```
Buatkan price list untuk [NAMA USAHA JASA]. Daftar layanan:
[LAYANAN 1 - HARGA], [LAYANAN 2 - HARGA], dst.
Susun dari paket termurah ke termahal (anchoring).
Tambahkan paket bundling [BUNDLE] sebagai "paling laris".
Sertakan catatan: [mis. "harga di luar [AREA] + transport"].
Format rapi siap copy ke WhatsApp/brosur.
```

## 5. Meminta Testimoni Setelah Layanan

```
Buatkan pesan untuk meminta testimoni setelah menyelesaikan
[LAYANAN] untuk klien [NAMA/ PANGGILAN]. Timing: [mis. H+1
setelah layanan]. Buat semudah mungkin: berikan 3 pertanyaan
panduan singkat yang tinggal dijawab. Tawarkan insentif
[mis. diskon 10% kunjungan berikutnya]. Hangat dan personal,
maksimal 80 kata.
```

## 6. Menangani Komplain dengan Elegan

```
Buatkan respons untuk komplain: "[COPY-PASTE KOMPLAIN]".
Struktur: akui & minta maaf tulus → jelaskan singkat tanpa
berdalih → tawarkan solusi konkret [SOLUSI, mis. gratis
perbaikan + voucher] → tutup dengan komitmen.
Nada: profesional, empati, tidak defensif. Maksimal 120 kata.
Catatan: respons ini juga dibaca calon klien lain.
```

## Tips Khusus Usaha Jasa

- 🤝 **Jasa = kepercayaan.** 70% keputusan pakai jasa didorong testimoni & portofolio. Prioritaskan template #2 dan #5.
- 💰 **Jangan perang harga.** Kalau prompt-mu selalu minta "buat yang termurah", kamu melatih AI (dan dirimu) bersaing di harga. Minta "tekankan value dan garansi" sebagai gantinya.
- 📋 **Price list mencegah PHP.** Calon klien yang sudah lihat harga jelas 3x lebih serius daripada yang masih tanya-tanya. Template #4 wajib punya.
- 🔁 **Sistem > bakat.** Salon/bengkel yang punya template follow-up (#3) dan template testimoni (#5) akan selalu lebih ramai dari yang mengandalkan ingatan.
