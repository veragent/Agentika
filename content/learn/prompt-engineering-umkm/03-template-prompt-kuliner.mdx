# Template Prompt untuk Usaha Kuliner

Template khusus untuk warung makan, katering, snack, minuman, dan semua usaha kuliner. Ganti [KURUNG] dengan info usahamu.

## 1. Deskripsi Menu Andalan

```
Kamu adalah food copywriter. Buatkan deskripsi menggugah selera untuk
menu [NAMA MENU], harga [HARGA].

Detail: [BAHAN UTAMA, mis. ayam kampung, sambal matah homemade].
Keunggulan: [mis. dimasak dadakan, resep keluarga 20 tahun].

Maksimal 60 kata, bikin pembaca lapar hanya dengan membaca.
Akhiri dengan ajakan order.
```

## 2. Caption Harian (Anti Kehabisan Ide)

```
Buatkan 7 caption Instagram untuk [NAMA USAHA], masing-masing untuk
1 hari dalam seminggu. Tema bergantian: produk, edukasi, testimoni,
behind-the-scenes, promo, interaksi, dan storytelling.

Info usaha: [JENIS MAKANAN], lokasi [LOKASI], harga [RANGE].
Gaya santai, maksimal 80 kata per caption, sertakan 3-5 hashtag.
```

## 3. Pengumuman Menu Baru

```
Buatkan pengumuman launching menu baru: [NAMA MENU].
Ceritakan kenapa menu ini spesial: [ALASAN, mis. request pelanggan
terbanyak selama 3 bulan]. Bangun rasa penasaran.
Sertakan info: tersedia mulai [TANGGAL], harga [HARGA],
stok terbatas [JUMLAH]/hari. Maksimal 120 kata.
```

## 4. Copy Promo GoFood/GrabFood/ShopeeFood

```
Buatkan copy promo untuk aplikasi pesan-antar: [NAMA PROMO,
mis. Diskon 40%]. Syarat: [SYARAT, mis. min. belanja Rp 40rb].
Berlaku [PERIODE]. Tekankan kemudahan: "mager? tinggal klik".
Maksimal 50 kata — orang scroll cepat di aplikasi.
```

## 5. Script Video "Proses Masak" (30-60 Detik)

```
Buatkan script video pendek yang menunjukkan proses pembuatan
[PRODUK]. Struktur: hook 3 detik ([masalah/pertanyaan mengejutkan]),
proses 30 detik (tulis tahapan [TAHAP 1, 2, 3]), closing
([lokasi + jam buka]). Tulis arahan visual dalam kurung siku.
Nada: autentik, tidak terlalu "iklan".
```

## 6. Balasan Review Negatif

```
Buatkan template balasan profesional untuk review negatif:
"[COPY-PASTE REVIEW]". Nada: minta maaf tulus, tidak defensif,
tawarkan solusi [SOLUSI, mis. ganti rugi/voucher].
Akhiri dengan undangan untuk kembali. Maksimal 80 kata.
Penting: balasan ini dibaca calon pembeli lain juga.
```

## Tips Khusus Kuliner

- 📸 **Kata sifat makanan itu penting.** Minta AI pakai kata sensorik: "renyah di luar, lumer di dalam", "kuah medok", "sambal nendang". Kalau hasilnya hambar, tambahkan: "gunakan kata-kata yang membangkitkan selera".
- 🕐 **Waktu posting = waktu lapar.** Caption makan siang diposting jam 10-11, makan malam jam 16-17. Sebutkan di prompt: "buat versi untuk diposting jam 10 pagi".
- 🔁 **Daur ulang.** Satu deskripsi menu bisa jadi: caption, teks brosur, script video, dan balasan chat — minta AI "adaptasi untuk [format]".

> **Latihan:** Pilih 2 template di atas, isi dengan menu andalanmu, jalankan sekarang. Posting yang terbaik hari ini juga.
