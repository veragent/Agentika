# Template Prompt untuk Fashion & Retail

Template khusus untuk toko baju, hijab, sepatu, aksesoris, dan retail pada umumnya.

## 1. Deskripsi Produk Fashion

```
Kamu adalah fashion copywriter. Buatkan deskripsi untuk [NAMA PRODUK],
harga [HARGA].

Detail: bahan [JENIS KAIN], tersedia ukuran [UKURAN],
warna [WARNA]. Target: [mis. wanita 20-35 tahun, gaya kasual].

Sertakan: kesan saat dipakai, kecocokan untuk acara [ACARA],
dan info perawatan singkat. Maksimal 100 kata.
Akhiri dengan urgensi stok yang natural.
```

## 2. Caption "New Arrival"

```
Buatkan caption untuk koleksi baru: [NAMA KOLEKSI, mis. "Seri Lebaran 2026"].
Highlight 3 item unggulan: [ITEM 1 + harga], [ITEM 2 + harga], [ITEM 3 + harga].
Bangun excitement seperti unboxing. Sertakan info cara order
dan jam live shopping berikutnya [JADWAL]. Maksimal 120 kata + hashtag.
```

## 3. Script Live Shopping

```
Buatkan script live shopping 60 menit untuk [NAMA TOKO].
Produk yang dibahas: [DAFTAR 5-8 PRODUK + harga masing-masing].

Struktur per produk (5 menit): hook pembuka, detail bahan & ukuran,
cara order (ketik [FORMAT ORDER]), closing dengan penawaran terbatas.
Sertakan juga: opening 5 menit (sapa + info flash sale) dan
closing 5 menit (rekap + pengingat pembayaran). Nada energik dan ramah.
```

## 4. Copy Bundle/Paket Hemat

```
Buatkan copy penawaran bundling: [ISI BUNDLE, mis. 2 dress + 1 hijab].
Harga satuan total [TOTAL], harga bundle [HARGA BUNDLE]
(hemat [SELISIH]). Tekankan nilai hematnya tanpa terkesan murahan.
Beri nama paket yang menarik: [mis. "Paket Bestie"].
Maksimal 100 kata.
```

## 5. Caption "Restock" / Stok Terbatas

```
Buatkan caption restock untuk [NAMA PRODUK] yang kemarin sold out.
Info: restock [JUMLAH] pcs, yang kemarin kehabisan [estimasi, mis. 50 orang]
sudah waiting list. Dorong untuk gercep tanpa terkesan menekan.
Sertakan cara order tercepat. Maksimal 80 kata.
```

## 6. Panduan Ukuran (Size Guide) yang Menjual

```
Buatkan panduan ukuran untuk [JENIS PRODUK, mis. dress] yang ramah pembeli online.
Format tabel: Ukuran | Lingkar Dada | Panjang | Cocok untuk BB/TB.
Tambahkan tips: "kalau ragu antara 2 ukuran, pilih [SARAN]".
Akhiri dengan jaminan: [mis. "salah ukuran? tukar gratis 7 hari"].
```

## Tips Khusus Fashion & Retail

- 📏 **Ukuran adalah penentu konversi.** 60% keraguan beli online adalah soal ukuran. Template #6 bisa menaikkan closing rate secara signifikan.
- 🎥 **Live > foto untuk fashion.** Orang mau lihat "jatuhnya kain" saat dipakai bergerak. Script live (#3) bikin kamu pede walau baru pertama kali.
- 💬 **Bahasa komunitas.** Fashion punya bahasa sendiri ("flowy", "adem", "nggak nerawang"). Minta AI: "gunakan istilah yang dipakai komunitas hijabers/fashion lokal".
- 📦 **Foto + copy = paket.** Template ini paling powerful kalau dipasangkan dengan foto produk yang rapi (lihat studi kasus [Mbak Rina](/blog/umkm-case-studies/toko-fashion-solo-naik-2x-omzet-ai)).

> **Latihan:** Ambil 1 produk terlarismu, jalankan template #1 dan #5. Update deskripsi di katalog WA/tokomu hari ini.
