# Prompt Engineering untuk UMKM: 50+ Template Siap Pakai

Nggak perlu pusing bikin prompt dari nol. Copy-paste template di bawah, ganti `[VARIABEL]`, jalankan di ChatGPT/Claude/Gemini. Hasil: konten siap publish dalam menit.

## Framework Prompt Universal (Pakai untuk Semua)

```
PERAN: [Mis: Copywriter senior UMKM Indonesia, 10 th pengalaman]
KONTEKS: [Bisnis: Warung makan "Bu Siti" di Depok. Menu: Nasi Goreng, Mie Goreng, Ayam Goreng. Target: Ibu rumah tangga & karyawan 25-45 th]
TUGAS: [Tulis 5 caption Instagram untuk prom menu baru "Nasi Goreng Spesial Seafood"]
FORMAT: [Tabel | Judul | Caption (max 2200 char) | Hashtag (15) | CTA | Emoji]
GAYA: [Hangat, kekinian, bahasa sehari-hari, nggak kaku, pake "gue/loe" ringan]
BATASAN: [Jangan gunakan kata "gratis" berlebihan, hindari janji berlebihan, comply BPOM]
CONTOH: [Contoh caption sebelumnya yang performa bagus: "..."]
```

## 1. KONTEN SOSIAL MEDIA (Instagram, TikTok, LinkedIn)

### 1.1 Kalender Konten 30 Hari
```
Buatkan kalender konten [PLATFORM] 30 hari untuk [JENIS BISNIS] di [LOKASI].
Menu/Produk: [DAFTAR MENU]
Target Audience: [DEMOGRAFI]
Content Pillars: [4 PILAR: mis. Produk, Edukasi, Social Proof, Promo]
Format Output: Tabel | Tanggal | Tipe (Foto/Reels/Story/Carousel) | Hook/Judul | Caption Ringkas | Hashtag (15) | CTA | Catatan Visual
Tone: [Casual/Profesional/Hangat/Enerjik]
Frekuensi Posting: [3-5x/minggu]
```

### 1.2 Caption Instagram (Educational)
```
Tulis caption Instagram edukatif tentang [TOPIK: mis. "Rahasia nasi goreng wangi & berserat"].
Target: [AUDIENCE]
Struktur: Hook (1 baris) → Value (3-5 poin actionable) → Personal Story (1-2 kalimat) → CTA (komentar/save/share) → Hashtag (15)
Panjang: 1500-2000 karakter.
Gaya: [Hangat/Expert/Friendly], gunakan formatting (line break, emoji, bullet).
Jangan: Jargon terlalu teknis, hard-sell.
```

### 1.3 Script Reels/TikTok 15-30 Detik
```
Buatkan script Reels/TikTok 30 detik untuk [PRODUK/JASA].
Format: Tabel | Detik | Visual (Apa yang di kamera) | Audio/Narasi | Teks Overlay | Catatan Editing
Struktur: Hook (0-3s) → Value/Process (3-20s) → Result (20-27s) → CTA (27-30s)
Durasi Total: 30 detik (bisa dipotong jadi 15s & 60s).
Musik: [Saran: trending/upbeat/asmr]
Caption: [Auto-generate dari script]
```

### 1.4 Carousel "How-To" / Tips
```
Buatkan konten Carousel 7 slide untuk [TOPIK: mis. "5 Cara Membedakan Beras Berkualitas"].
Slide 1: Cover (Judul + Hook + Branding)
Slide 2-6: 1 Tips per slide (Visual suggestion + Teks singkat max 2 baris)
Slide 7: Ringkasan + CTA (Follow/Save/Share) + Branding
Format: Tabel | Slide | Judul | Isi Teks | Saran Visual | Alt Text
```

### 1.5 Story Interaktif (Poll, Quiz, Q&A)
```
Buatkan 5 ide Instagram Story interaktif untuk engagement [BISNIS].
Jenis: 2 Poll, 1 Quiz, 1 Q&A Box, 1 Slider (Emoji).
Format: Tabel | Jenis | Pertanyaan | Opsi Jawaban | Follow-up Action (mis. kirim DM link menu) | Visual Suggestion
```

### 1.6 LinkedIn Thought Leadership (B2B/Service)
```
Tulis post LinkedIn profesional untuk [FOUNDER/CEO] [BISNIS B2B].
Topik: [MIS. "Kenapa UMKM Butuh Otomasi Order Sekarang"]
Struktur: Hook (masalah nyata) → Insight/Data (3 poin) → Solusi Praktis → Personal Take → CTA (Komentar/DM/Konsultasi)
Tone: Otoritatif tapi humble, bahasa Indonesia formal tapi nggak kaku.
Panjang: 1300-2000 karakter. 5-8 hashtag relevan.
```

## 2. COPYWRITING IKLAN (Meta Ads, Google Ads, WA Blast)

### 2.1 Meta Ads: Awareness (Video View / Reach)
```
Tulis 3 variasi Primary Text + Headline + Description untuk Meta Ads Awareness.
Produk: [NAMA PRODUK + USP]
Target: [DEMOGRAFI + MINAT]
Format Iklan: [Reels/Carousel/Single Image]
Objective: Brand Awareness / Video Views
Komponen:
- Primary Text: 125 char (Hook + Benefit + Social Proof + CTA)
- Headline: 40 char (Benefit-driven)
- Description: 30 char (Urgency/Trust signal)
Tone: [Enerjik/Emosional/Logis]
Emoji: Ya (sedikit)
```

### 2.2 Meta Ads: Conversion (Sales / Lead)
```
Tulis 3 variasi copy Meta Ads Conversion untuk [PRODUK/JASA].
USP: [KEUNIKAN PRODUK]
Harga: [HARGA + PROMO JIKA ADA]
Garansi/Trust: [GARANSI/MONEY BACK/TESTIMONI]
Format:
- Primary Text: PAS Formula (Problem → Agitation → Solution) + CTA
- Headline: Benefit + Urgency (mis. "Diskon 30% Hingga Minggu Ini")
- Description: Trust signal (mis. "1000+ Pelanggan Puas | COD Tersedia")
Landing Page: [URL]
Pixel Event: Purchase / Lead / Contact
```

### 2.2 Google Ads: Search (Responsive Search Ads)
```
Buatkan 15 Headline (max 30 char) + 4 Description (max 90 char) untuk RSA Google Ads.
Keyword Target: [DAFTAR KEYWORD]
Produk: [NAMA + USP]
USP: [3 KEUNGULAN UTAMA]
Extension: Sitelink (4), Callout (4), Structured Snippet
Brand Terms: [NAMA BRAND] - exclude dari campaign non-brand
Negative Keywords: [gratis, murah, second, bekas, tutorial, cara, review]
```

### 2.3 WhatsApp Blast (Broadcast)
```
Tulis 3 variasi pesan WA Blast untuk [KEGIATAN: Promo/Launch/Event].
Panjang: Max 3 blok teks (WhatsApp truncate di blok ke-3).
Struktur: Greeting Personal → Hook (Benefit/Urgen) → Detail Singkat → CTA Link/Reply → Closing Ramah.
Personalisasi: Gunakan {{nama}} dari database.
Compliance: Wajib ada "Balas STOP untuk berhenti" di akhir.
Timing: Kirim jam 10:00 / 16:00 / 19:30 (test A/B).
```

### 2.4 Email Marketing (Welcome Sequence / Promo)
```
Tulis email [JENIS: Welcome Series 3 hari / Promo Flash Sale / Abandoned Cart / Re-engagement].
Subjek: 3 variasi (Curiosity / Benefit / Urgency) - max 50 char.
Preheader: 1 variasi - max 100 char.
Body: Hook → Story/Value → Offer → CTA Button → Social Proof → Unsubscribe.
Tone: Personal (seperti ngechat temen), nggak "marketing banget".
Format: HTML-ready (heading, paragraph, button, image placeholder).
```

## 3. CUSTOMER SERVICE & FAQ

### 3.1 Template Balasan Umum (Copy-Paste ke Saved Replies)
```
Buatkan 10 template balasan WA/Email untuk FAQ [BISNIS].
Kategori: Harga, Pengiriman, Retur, Komposisi, Halal, Custom, Komplain, Komplimen, Tanya Stok, Tanya Metode Bayar.
Format: Tabel | Kategori | Trigger Keyword | Template Balasan (pakai {{nama}}, {{nomor_order}}, {{link}}) | Tone | Estimasi Waktu Balas
Syarat: Ramah, jelas, actionable (kasih next step), comply UU Perlindungan Konsumen.
```

### 3.2 Handling Komplain (Framework HEART)
```
Buatkan script handling komplain untuk [JENIS KOMPLAIN: Telat kirim / Salah barang / Rusak / Rasa nggak cocok].
Framework HEART:
H - Hear (Dengar dulu, validasi perasaan)
E - Empathize (Ucapkan maaf tulus, bukan template)
A - Apologize (Minta maaf spesifik, bukan umum)
R - Resolve (Berikan solusi konkret + timeline)
T - Thank (Terima kasih sudah beri tahu, tawarkan goodwill)
Output: Script percakapan WA/Telepon + Template Email follow-up + SOP Eskalasi ke Manajer.
```

### 3.3 Upsell & Cross-sell Script
```
Buatkan script upsell/cross-sell untuk [PRODUK UTAMA] saat checkout / pasca beli.
Produk Tambahan: [DAFTAR PRODUK RELEVAN + HARGA + MARGIN]
Teknik: Bundling (hemat 10%) / Upgrade (versi premium) / Subscription (langganan bulanan)
Script WA: "Sebelum dibayar, mau coba [PRODUK TAMBAHAN]? Cuma +Rp [HARGA] dari harga normal Rp [NORMAL]. Hemat Rp [SELISIH] 😉"
Kondisi: Hanya tawar jika margin > 30% & relevan.
```

## 4. ANALISIS BISNIS & STRATEGI

### 4.1 SWOT Analysis (ChatGPT sebagai Konsultan)
```
Lakukan analisis SWOT untuk [NAMA BISNIS].
Info Bisnis: [JENIS, LOKASI, OMZET, TIM, PRODUK, TARGET, KOMPETITOR]
Output: Tabel 2x2 | Strengths (Internal +) | Weaknesses (Internal -) | Opportunities (Eksternal +) | Threats (Eksternal -)
Lalu: 3 Rekomendasi Strategis Prioritas (Quick Win / Big Bet / Foundation) dengan:
- Aksi Spesifik
- Timeline
- Resource Butuh
- KPI Sukses
- Risiko & Mitigasi
```

### 4.2 Competitor Analysis
```
Analisis 3 kompetitor utama [BISNIS] di [LOKASI].
Data Input: [Nama Kompetitor, Instagram/Website, Harga, Menu/Produk, Promo, Review Rating]
Output: Tabel Perbandingan | Fitur | Kita | Kompeten 1 | Kompeten 2 | Kompeten 3 | Gap | Opportunity
Insight: 3 Hal yang Bisa Diadopsi, 3 Hal yang Bisa Dibedakan, 1 Hal yang Harus Dihindari.
```

### 4.3 Customer Persona Builder
```
Buatkan 3 Customer Persona detail untuk [BISNIS].
Format per Persona: Nama Fiktif | Demografi (Usia, Lokasi, Pekerjaan, Penghasilan) | Psychografi (Nilai, Minat, Rasa Takut, Keinginan) | Pain Points (3) | Goals (3) | Journey Stage (Awareness → Consideration → Decision → Loyalty) | Channel Favorit | Content Yang Disukai | Objection Umum | Key Message Untuk Konversi.
```

### 4.4 Content Gap Analysis (SEO)
```
Identifikasi content gap untuk [BISNIS] di niche [NICHE].
Input: [Daftar 50 Keyword Target + Volume + KD + Current Ranking (kalau ada)]
Output: Tabel | Keyword | Volume | KD | Current Rank | Competitor Rank | Content Type Needed (Review/How-to/Comparison/Listicle) | Priority (High/Med/Low) | Estimated Traffic | Effort (1-5)
Rekomendasi: 10 Artikel Prioritas Bulan Ini.
```

### 4.5 Pricing Strategy Analysis
```
Analisis strategi harga untuk [PRODUK/JASA].
Input: COGS, Competitor Price, Target Margin, Perceived Value, Price Sensitivity Audience.
Output:
1. Cost-Plus Price (baseline)
2. Competitive Price (market rate)
3. Value-Based Price (recommended)
4. Psychological Price (charm pricing .99/.95)
5. Bundle/Tier Pricing (Good/Better/Best)
6. Promo Calendar (Quarterly)
Rekomendasi: Harga Jual Optimal + Justifikasi.
```

## Cara Pakai Efektif (Best Practice)

| Prinsip | Penjelasan |
|---------|------------|
| **Satu Prompt Satu Tugas** | Jangan minta "buat konten + analisis + jadwal" sekaligus. Pecah jadi 3 prompt. |
| **Berikan Konteks Lengkap** | Siapa, apa, untuk siapa, di mana, kapan, kenapa, bagaimana. |
| **Gunakan Few-Shot** | Kasih 2-3 contoh Input→Output yang ideal. Drastis naikkan akurasi. |
| **Iterasi, Bukan Sekali Jadi** | Prompt → Review → Perbaiki Prompt → Ulangi. Biasanya 2-3 iterasi sudah bagus. |
| **Simpan yang Berhasil** | Bangun library prompt pribadi di Notion/Obsidian. Tag: `#sosmed #iklan #cs #strategi`. |
| **Test A/B Prompt** | Sama task, beda prompt → bandingkan output → pilih terbaik → jadikan standard. |
