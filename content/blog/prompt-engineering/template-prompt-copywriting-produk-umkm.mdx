# 20 Template Prompt Copywriting Siap Pakai untuk UMKM (Tinggal Copy-Paste)

Copywriting yang bagus bikin orang beli. Kabar baiknya: kamu nggak perlu jadi penulis hebat — cukup kasih instruksi yang tepat ke AI. Di bawah ini 20 template prompt yang bisa langsung dipakai. **Ganti semua teks dalam [KURUNG] dengan info usahamu.**

> **Tips pakai:** Makin spesifik info yang kamu masukkan, makin bagus hasilnya. Jangan tulis "[produk]" doang — tulis "[Risol Mayo isi 5, Rp 15 ribu]".

---

## Deskripsi Produk (5 template)

### 1. Deskripsi Produk Standar
```
Buatkan deskripsi produk untuk [NAMA PRODUK], harga [HARGA].
Bahan/isi: [DETAIL]. Keunggulan: [KEUNGGULAN].
Target pembeli: [TARGET, mis. ibu-ibu 25-40 tahun].
Gaya bahasa friendly dan meyakinkan, maksimal 100 kata.
Akhiri dengan ajakan untuk order via WhatsApp.
```

### 2. Deskripsi Produk Premium/Mahal
```
Buatkan deskripsi produk premium untuk [NAMA PRODUK], harga [HARGA].
Tekankan kualitas bahan [DETAIL BAHAN], proses pembuatan [PROSES],
dan kenapa harganya worth it dibanding kompetitor.
Gaya bahasa elegan, tidak terkesan murahan. Maksimal 120 kata.
```

### 3. Deskripsi Produk Diskon/Promo
```
Buatkan deskripsi promo untuk [NAMA PRODUK].
Harga normal [HARGA NORMAL], harga promo [HARGA PROMO],
berlaku sampai [TANGGAL]. Ciptakan rasa urgensi tanpa terkesan maksa.
Sertakan 3 alasan kenapa harus beli sekarang. Maksimal 100 kata.
```

### 4. Deskripsi untuk Produk Baru/Launching
```
Buatkan pengumuman launching produk baru: [NAMA PRODUK].
Ceritakan singkat kenapa produk ini dibuat ([ALASAN/LATAR BELAKANG]).
Bangun antisipasi dan rasa penasaran. Akhiri dengan info
kapan dan di mana bisa dibeli. Gaya bahasa excited, maksimal 120 kata.
```

### 5. Perbandingan dengan Kompetitor (tanpa sebut merek)
```
Buatkan copy yang menjelaskan kenapa [NAMA PRODUK] lebih unggul.
Bandingkan 3 aspek: [ASPEK 1, mis. bahan], [ASPEK 2, mis. harga],
[ASPEK 3, mis. pengiriman]. Jangan sebut merek kompetitor,
fokus pada keunggulan kita. Gaya percaya diri tapi tidak sombong.
```

## Caption Media Sosial (5 template)

### 6. Caption Instagram Edukasi
```
Buatkan caption Instagram edukatif tentang [TOPIK, mis. cara memilih beras untuk nasi goreng].
Hubungkan dengan produkku [NAMA PRODUK] secara natural di akhir.
Panjang 100-150 kata, sertakan 5 hashtag relevan.
Gaya bahasa santai seperti ngobrol dengan teman.
```

### 7. Caption Testimoni Pelanggan
```
Buatkan caption testimoni berdasarkan review ini: "[COPY-PASTE REVIEW ASLI]".
Kemaskan jadi cerita yang meyakinkan, tambahkan ajakan untuk
coba produk [NAMA PRODUK]. Jangan mengarang fakta baru di luar review.
Panjang 80-120 kata + hashtag.
```

### 8. Caption Behind The Scenes
```
Buatkan caption behind-the-scenes untuk [KEGIATAN, mis. proses masak jam 4 pagi].
Tunjukkan kerja keras dan ketulusan di balik produk [NAMA PRODUK].
Bangun kedekatan emosional dengan follower. Gaya hangat dan jujur,
maksimal 120 kata.
```

### 9. Caption Flash Sale
```
Buatkan caption flash sale: [NAMA PRODUK] diskon [BESAR DISKON],
hanya [DURASI, mis. 3 jam hari ini]. Ciptakan urgensi yang kuat.
Sertakan cara order yang jelas ([CARA ORDER]).
Maksimal 80 kata, to the point.
```

### 10. Caption Storytelling Brand
```
Ceritakan kisah brand [NAMA BRAND]: mulai dari [AWAL MULA],
tantangan [TANTANGAN], sampai sekarang [KONDISI SEKARANG].
Bikin pembaca merasa terhubung dan bangga mendukung UMKM lokal.
Panjang 150-200 kata, gaya naratif yang menyentuh.
```

## Broadcast WhatsApp (4 template)

### 11. Broadcast Koleksi/Produk Baru
```
Buatkan pesan broadcast WhatsApp untuk info [PRODUK BARU].
Sapa dengan hangat, jelaskan singkat keunggulannya,
kasih harga [HARGA] dan cara order. Maksimal 60 kata —
orang malas baca broadcast panjang. Akhiri dengan emoji yang pas.
```

### 12. Broadcast Promo Terbatas
```
Buatkan pesan broadcast promo: [DETAIL PROMO], khusus untuk
[SEGMENT, mis. pelanggan yang pernah beli]. Buat mereka merasa
spesial dan diprioritaskan. Sertakan kode promo [KODE] jika ada.
Maksimal 70 kata.
```

### 13. Follow-up Keranjang (yang nanya tapi belum beli)
```
Buatkan pesan follow-up sopan untuk calon pembeli yang kemarin
nanya tentang [NAMA PRODUK] tapi belum order. Jangan terkesan
memaksa. Tawarkan bantuan atau info tambahan [INFO].
Maksimal 50 kata, gaya ramah.
```

### 14. Minta Testimoni/Review
```
Buatkan pesan untuk meminta testimoni dari pelanggan yang
baru beli [NAMA PRODUK]. Buat semudah mungkin: kasih contoh
format jawaban singkat. Tawarkan [INSENTIF, mis. voucher Rp 10rb]
sebagai terima kasih. Maksimal 60 kata.
```

## Iklan Berbayar (3 template)

### 15. Primary Text Meta Ads
```
Buatkan primary text untuk iklan Meta Ads produk [NAMA PRODUK].
Hook di 2 baris pertama harus menohok ([MASALAH TARGET]).
Sertakan social proof: [DATA, mis. 2.000+ terjual].
Akhiri dengan CTA jelas. Maksimal 125 karakter untuk hook,
total maksimal 300 karakter.
```

### 16. Headline Iklan
```
Buatkan 5 pilihan headline iklan untuk [NAMA PRODUK], masing-masing
maksimal 40 karakter. Variasi sudut: manfaat, harga, urgensi,
social proof, dan rasa penasaran.
```

### 17. Script Iklan Video 30 Detik
```
Buatkan script iklan video 30 detik untuk [NAMA PRODUK].
Struktur: hook 3 detik ([HOOK]), masalah 7 detik,
solusi + demo produk 12 detik, CTA 8 detik.
Tulis juga arahan visual per segmen dalam kurung.
```

## Layanan & Operasional (3 template)

### 18. Balasan FAQ Otomatis
```
Buatkan 10 pasangan Q&A untuk auto-reply WhatsApp bisnis [NAMA USAHA].
Topik: jam buka [JAM], lokasi [LOKASI], harga [RANGE HARGA],
cara order [CARA], estimasi pengiriman [ESTIMASI], pembayaran [METODE].
Jawaban singkat, maksimal 30 kata per jawaban.
```

### 19. SOP Singkat untuk Karyawan
```
Buatkan SOP sederhana untuk [TUGAS, mis. packing order online]
di usaha [NAMA USAHA]. Langkah-langkah bernomor, bahasa sederhana,
maksimal 15 langkah. Sertakan checklist verifikasi di akhir.
```

### 20. Email/Proposal Kerjasama
```
Buatkan draft pesan penawaran kerjasama untuk [TARGET KERJASAMA,
mis. reseller/katering kantor]. Perkenalkan [NAMA USAHA] singkat,
jelaskan skema kerjasama [SKEMA] dan keuntungannya untuk mereka.
Profesional tapi tidak kaku. Maksimal 200 kata.
```

## Cara Dapat Hasil Terbaik

1. **Jangan pakai mentah-mentah.** Hasil AI adalah draft — baca ulang, sesuaikan dengan gaya bicaramu.
2. **Beri contoh.** Tambahkan "contoh gaya yang aku suka: [paste caption lamamu]" di akhir prompt untuk hasil yang lebih konsisten.
3. **Iterasi.** Kalau hasilnya kurang nendang, balas dengan "buat lebih [lucu/formal/santai]" atau "persingkat jadi setengahnya".
4. **Simpan yang bagus.** Bikin dokumen kumpulan hasil terbaikmu — lama-lama kamu punya "bank copywriting" sendiri.

> **Mulai sekarang:** Pilih 3 template yang paling kamu butuhkan minggu ini, isi [KURUNG]-nya, dan jalankan. Rasakan bedanya dalam 7 hari.
